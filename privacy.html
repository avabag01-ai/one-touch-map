개인정보처리방침

시행일: 2026년 6월 27일 | 최종 수정: 2026년 6월 27일

1. 수집하는 개인정보 항목

원터치 에어(이하 "앱")는 다음의 정보를 수집합니다:

  • 위치 정보: 현재 위치 기반 경로 안내 및 지도 표시 (사용 중에만 수집)
  • 배송지 주소: 사용자가 직접 입력한 배송 주소 및 관련 메모 (기기 내 저장)
  • 카메라/사진: 배송전표 OCR 인식 시 일시 사용, 서버에 전송하지 않음

2. 개인정보의 수집 목적

  • 배송 경로 최적화 및 지도 표시
  • 배송전표 자동 인식(OCR) 기능 제공
  • 배송 현황 관리

3. 개인정보의 보유 및 이용 기간

수집된 정보는 기기 내 로컬 저장소(localStorage)에만 저장되며, 외부 서버로 전송되지 않습니다. 사용자가 앱을 삭제하거나 데이터를 초기화하면 즉시 삭제됩니다.

4. 개인정보의 제3자 제공

앱은 수집한 개인정보를 제3자에게 제공하지 않습니다. 단, 주소 검색 시 국가 공공 API(VWorld)를 통해 주소 데이터를 조회하며, 이 과정에서 입력된 주소 텍스트가 해당 서버에 전달될 수 있습니다.

5. 사용하는 외부 서비스

  • VWorld API (국토교통부): 주소 검색 및 지도 타일
  • Tesseract.js: 기기 내 OCR 처리 (네트워크 전송 없음)

6. 사용자의 권리

사용자는 언제든지 앱 내 설정에서 저장된 배송 데이터를 삭제할 수 있으며, 앱 삭제 시 모든 로컬 데이터가 함께 삭제됩니다.
