원터치맵 사용 설명서

배송기사님을 위한 원터치 주소 입력 · 경로 최적화 · 도착 알림 앱

목차 1. 주소 입력 2. OCR 사진 인식 3. 배송 목록 4. 최적경로 5. 지도 6. 도착 알림 7. 알림 반경 설정 8. 처음 설정 (중요)

1. 주소 입력 — 원터치 키패드

앱을 열면 나오는 첫 화면. 운전 중에도 한 손으로 빠르게.
  • 주소전에 번지수만 쳐도 주소후에 완성된 주소가 자동으로 떠요.
  • 로 길 안길 가길~라길 키로 도로명도 원터치.
  • 동 선택 버튼으로 지역을 고르면 그 동네 주소로 좁혀서 찾아요. 전국코드로 다른 지역도 검색.
  • 긴급 체크 후 등록하면 목록에서 빨간 표시로 우선 표시돼요.
  • 배송등록 = 지금 주소를 목록에 추가, 배송주소 = 배송 목록 화면으로 이동.

2. OCR 사진 인식 — 송장 찍으면 주소 자동 등록

배송 목록 화면의 OCR 인식 버튼
1

송장이나 배송 리스트 종이를 사진으로 찍거나 앨범에서 선택해요.

2

주소가 있는 부분만 손가락으로 드래그해 선택하면 인식률이 확 올라가요. (전체 사용도 가능)

3

스캔 결과에서 맞는 주소만 체크하고 일괄 등록. 빠진 건 + 직접 추가하기로.

3. 배송 목록 — 하루 배송 관리

홈에서 배송주소를 누르면 나오는 화면
  • 날짜별로 목록이 나뉘어요. 상단 날짜를 눌러 다른 날 목록도 확인.
  • 주소를 누르면 지도에서 위치를 바로 보여줘요.
  • 📷 버튼으로 현장(문 앞) 사진 저장 — 찍어두면 📸로 바뀌어요.
  • 전화번호·메모 입력, 톤수 배지, 긴급(빨간 테두리) 표시.
  • 지금갈곳 저장 — 체크한 주소만 따로 묶어 지도와 연동. 해제로 풀어요.
  • 체크 후 삭제로 완료한 배송지 정리.

4. 🚀 최적경로 — 최단 코스로 자동 정렬

배송 목록 오른쪽 위 🚀최적경로 버튼
1

GPS로 현재 위치를 잡아요.

2

좌표 없는 주소는 자동으로 좌표를 계산해요.

3

현재 위치에서 출발하는 최단 경로 순서로 목록이 다시 정렬돼요. 순번이 곧 배송 순서!

💡 도착 알림만 쓸 거라면 최적경로를 안 돌려도 돼요. 도착 알림을 켤 때 좌표가 자동으로 계산돼요.

5. 지도 — 배송지를 한눈에

배송 목록의 지도 버튼
  • 등록된 배송지가 순번 마커로 표시돼요.
  • 최적경로를 돌린 뒤 보면 동선이 한눈에 들어와요.

6. 📍 도착 알림 — 에어팟 음성 + 워치 알림

배송 목록의 📍 도착알림 버튼 한 번이면 끝
알림 켜기
가장 가까운 배송지 감시
→
🎧 100m 접근
"다음 128 다시 46이요" 음성 예고
→
⌚ 20m 도착
워치·폰 알림 + 번지수 음성
→
자동 전환
다음 배송지 감시 시작
  • 버튼 한 번이면 등록된 배송지 전체가 대상이 돼요. 좌표가 없으면 그 자리에서 자동 계산.
  • 항상 제일 가까운 한 곳을 감시하고, 도착하면 자동으로 다음 배송지로 넘어가요.
  • 음성은 에어팟·차 스피커로 나와요. 음악이 나오는 중이면 잠깐 줄이고 말한 뒤 되돌려요.
  • 앱을 꺼도, 폰을 주머니에 넣어도 계속 작동해요. 앱을 재시작해도 설정이 유지돼요.
  • 운전 집중 모드(방해금지) 중에도 도착 알림은 뚫고 나와요.
  • 다시 누르면 꺼져요. 버튼이 초록색이면 켜진 상태.
⚠️ 이 기능은 설치된 앱에서만 동작해요(웹 브라우저 불가). 위치 권한을 "항상 허용"으로 해야 백그라운드에서도 알림이 와요.

7. ⚙️ 알림 반경 설정 — 울리는 거리를 내 맘대로

배송 목록의 ⚙️ 반경 버튼
  • 🎧 예고 음성 (에어팟): 50~300m — 이 거리에 들어오면 다음 배송지를 음성으로 미리 알려줘요.
  • ⌚ 도착 알림 (워치/폰): 10~100m — 이 거리에 들어오면 도착 알림이 울려요.
  • 알림이 켜진 상태에서 조절하면 즉시 반영돼요. 껐다 켤 필요 없어요.
  • 예고는 도착보다 항상 20m 이상 바깥으로 자동 유지돼요.
💡 GPS 특성상 10~30m 오차가 있을 수 있어요. 알림이 너무 늦게 오면 도착 반경을 30~50m로 넓혀보세요.

8. 처음 설정 — 이것만 해두면 편해요

1

위치 권한 "항상 허용" — 설정 > 원터치맵 > 위치 > 항상. 백그라운드 도착 알림의 필수 조건이에요.

2

알림 허용 — 도착알림을 처음 켤 때 묻는 알림 권한을 허용해 주세요.

3

워치에서 바로 번지수 보기 — 아이폰의 Watch 앱 > 알림 > "탭하여 전체 알림 보기" 끄기. 켜져 있으면 아이콘만 뜨고 터치해야 내용이 보여요.

4

미리보기 표시 — 설정 > 알림 > 미리보기 표시 > 항상. 잠금 화면·워치에서 번지수가 바로 보여요.
